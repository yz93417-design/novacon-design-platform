# 诺康莱集团设计中台管理系统

轻量级设计团队协作工具：设计排期 + 问题收集 + 渠道支持统计 + 花瓣收录集（素材相册）。纯 Node.js 实现，无第三方依赖，数据存本地 JSON，支持多人同时编辑（改动自动合并）。

## 功能

- **横向日历 / 时间轴**：按天排设计任务，支持图片素材粘贴/上传/下载/编辑、日期标色、备注
- **多系统 / 多页面**：平台化架构，可切换或新建多个系统（如：诺康莱、诺惠跨境）
- **数据统计**：渠道支持统计（点选渠道显示明细：活动时间、天数、图片张数、设计人、对接人）+ 四类可交互图表（柱状/饼状/折线/点状），支持导出 Excel/CSV
- **问题收集**：记录设计问题与解决方案，状态流转（未解决/解决中/已解决）
- **花瓣收录集**：设计素材相册，支持上传/粘贴 ⌘V/拖拽收录，单张或批量 复制/下载/分享/删除，大图预览
- **协作**：多人同时编辑，卡片级自动合并；可复制链接分享
- **其他**：暗色主题、移动端适配、语音输入、10 色统一色板

## 快速开始

```bash
node server.js
```

打开 http://localhost:3000 即可使用。本地默认仅监听回环地址。新工作区首次启动会创建空白看板。已有业务数据保存在原数据目录，请在切换分支或更新旧工作副本前单独备份最新的 `state.json`。

## 给客户 WorkBuddy 的部署提示词

> 请使用本账号已授权的云服务部署这个 Node.js 团队应用。先确认当前环境支持长期运行 Node HTTP 服务、HTTPS 入口和跨发布保留的可写卷，费用在已有额度内。用单个实例，更新时确保新旧实例不会同时写卷。若缺少这些条件，请列出缺项，保留现有服务并停在发布前。
>
> 使用本次修复版本和随附 Dockerfile 构建，或直接运行 `node server.js`。设置 `NODE_ENV=production`、平台指定的 `PORT` 和指向持久卷的 `DATA_DIR`。把整个目录挂载为可写，容器内 node 用户需要创建临时文件并重命名的权限。健康检查使用 `GET /api/health`。
>
> 优先配置客户现有的团队身份网关，覆盖网页和全部 API，验证源站也只能经过网关访问后设置 `TEAM_GATEWAY=1`。若客户接受团队共享账号，可改用平台密钥管理设置 `TEAM_USER` 和高强度 `TEAM_PASSWORD`，通过 HTTPS 登录。共享账号的所有成员都有编辑权限。
>
> 先用独立测试卷和合成数据演练。正式迁移时，暂停旧服务写入，从客户当前运行实例备份最新的 state.json，核对记录数量与文件校验值。仅首次导入到空卷的 `DATA_DIR/state.json`，已存在文件时停下核实。使用客户私有通道传输备份，勿把数据、密码或备份写入仓库、镜像、对话或日志。
>
> 切流量前验证未登录用户无法访问首页和状态 API、成员可使用，记录数与迁移前相符。用测试看板验证两人分别编辑不同卡片、新增对接人、刷新、重启及重新发布后数据都在。通过后交付 HTTPS 地址、登录方式、持久卷位置、备份与恢复步骤。失败时保留旧服务和新旧数据副本，确认数据版本后再回切。

## 技术说明

- 服务端：Node.js 原生 http 模块（无 npm 依赖），端口默认 3000（环境变量 `PORT` 可改）
- 前端：单文件 SPA（`public/index.html`），无框架无构建
- 同步：服务端权威状态 + 版本号递增 + 卡片级 merge，客户端 3 秒轮询拉取、编辑防抖推送
- 图片：base64 内联存储，canvas 压缩（最长边 1400px / 质量 0.75）
